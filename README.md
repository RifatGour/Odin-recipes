# Odin-recipes

This is my first recipes website made while learning HTML and CSS through [The Odin Project](https://www.theodinproject.com/).

## About

The website has a few recipe pages:

* Italian Mushroom Ravioli
* Chicken Biryani
* Chocolate Chip Cookies

The homepage links to each recipe, and every recipe page has a link back to the homepage.

## What I practiced

While making this project, I practiced:

* HTML boilerplate
* Headings and paragraphs
* Links and relative file paths
* Images and alt text
* Unordered and ordered lists
* Basic CSS
* Using an external CSS file
* Colors and background colors
* Font and text styling
* Margins and padding

## Project structure

odin-recipes/
